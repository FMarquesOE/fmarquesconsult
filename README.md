# fmarquesconsult

Site da consultoria Felipe Marques (pequenos negócios). Página única, Vite.

- `npm run dev` para editar
- `npm run build` gera a pasta `dist`
- Publicado no Vercel em https://fmarquesconsult.vercel.app (cada envio para a branch `main` publica sozinho)

Textos, pacotes e regras do site: `00_Referencia/CONTEXTO-PROJETO.md`, seção "Site da consultoria".

Formulário do diagnóstico (botões laranja → planilha do Google → WhatsApp): `docs/formulario-diagnostico.md`.
